# Characters

Metti qui i modelli dei gladiatori (Quaternius o Mixamo).

Consigliati:
- 2 personaggi diversi (o stesso con materiali diversi)
- Formato preferito: glTF / GLB o FBX
- Devono avere animazioni: Idle, Walk, Throw, Block, Hit, Fall, Victory

Dopo l’import in Stride assegna l’AnimationComponent al PlayerController.
