# Props

## Shield.fbx

- Origine: Blender (FBX IO 3.0)
- Tipo: mesh statica
- Materiali: Material.001 – Material.004
- Dimensione: ~291 KB

**Nota:** il file binario `Shield.fbx` è presente nella cartella locale del progetto (`/home/workdir/artifacts/DiscFaithful/assets/props/`).

Per caricarlo su GitHub:
1. Vai su https://github.com/SimonTek27/DiscFaithful
2. Naviga in `assets/props/`
3. Usa “Add file → Upload files” e seleziona `Shield.fbx`

Oppure da terminale (dopo aver clonato):
```bash
git add assets/props/Shield.fbx
git commit -m "Add Shield.fbx prop"
git push
```

### Uso in Stride
1. Copia `Shield.fbx` nella cartella Assets del progetto Stride
2. Importa come Model
3. Può essere usato come prop di prova / placeholder (non fa parte del gameplay originale di Disc)
